# Perfume Store Website — Client Commercial Proposals

A formal commercial proposal detailing service tiers, pricing options, package deliverables, and ownership structures for the Perfume Store website.

---

## 1. Commercial Pricing Overview

| Parameter | Option A: Fully Managed Service (Recommended) | Option B: Full Handover & Ownership |
|---|---|---|
| **Service Model** | Managed Retainer Service | Full Code & Admin Transfer |
| **Initial Upfront Fee** | **₹25,000** | **₹40,000** |
| **Ongoing Monthly Fee** | **₹1,500 / month** | **₹0 / month** |
| **1st Year Domain & Hosting** | Included | Included (All-Inclusive) |
| **Admin Panel Control** | Managed by Developer | Handed to Client (Full Access) |

| **Technical Support** | Continuous 24/7 Monitoring | 30 Days Post-Launch Support |

---

## 2. Package Option A: Fully Managed Service (₹25,000 + ₹1,500/Month)

### Investment Details:
- **Upfront Development & Setup:** ₹25,000
- **Monthly Maintenance Retainer:** ₹1,500 / month (starts Month 2)

### Scope of Deliverables Included:
- **Custom E-Commerce Platform:** Responsive mobile & desktop store, luxury Playfair typography, category & gender filters, bestseller badges, and instant search modal.
- **WhatsApp Checkout System:** Automated single-click order routing to owner's WhatsApp.
- **Customer Reviews Module:** Autoscrolling homepage reviews carousel, review submission modal, and full `/reviews` page.
- **1st Year Infrastructure Included:** `.com` or `.in` custom domain, 24/7 high-speed cloud hosting (zero sleep lag), free SSL security certificate.
- **Ongoing Maintenance Service:** 
  - Unlimited catalog image uploads and price/stock adjustments upon WhatsApp request.
  - 24/7 uptime monitoring, server security updates, and automated database backups.

---

## 3. Package Option B: Full Handover & Ownership (₹40,000 Flat Fee — All-Inclusive)

### Investment Details:
- **One-Time Flat Fee:** **₹40,000** (All-Inclusive of Deployment, Domain, Hosting & IP Handover)

### Scope of Deliverables Included:
- **All-Inclusive Deployment:** Complete setup of `.com` or `.in` domain, 1st year 24/7 dedicated cloud hosting, and free SSL certificate deployment (zero additional deployment fees).
- **Complete Source Code & IP Ownership:** Full repository transfer of all frontend and Node.js backend source code.
- **Full Admin Panel Master Credentials:** Admin login credentials for `/admin` granting complete control to add, edit, or delete products, change prices, and moderate reviews independently.
- **Server Account Transfer:** Registrar domain and server hosting accounts transferred to client's email address.
- **Client Training Session:** 45-minute walkthrough / training video explaining Admin Panel operation and photo formatting.
- **30-Day Priority Support Window:** 30 days of post-launch technical assistance.
